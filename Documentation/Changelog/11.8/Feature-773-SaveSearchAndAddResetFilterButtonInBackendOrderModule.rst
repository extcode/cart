=======================================================================
Feature: #773 - Save search and add reset filter button in order module
=======================================================================

See `Pull Request 773 <https://github.com/extcode/cart/pull/773>`__

Description
===========

The search arguments of the backend order module are saved in the module
data of the backend user. The filter is kept when switching pages and
when the module is opened again.

A "Reset filter" button is shown while a search is active. It clears the
saved search.

Impact
======

No direct impact.
