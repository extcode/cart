# Security Policy

## Supported Versions

Security updates are only provided for supported versions. The support status
of all versions is listed in the
[official extension documentation in chapter supported versions](https://docs.typo3.org/p/extcode/cart/main/en-us/Introduction/SupportedVersions/Index.html).

## Reporting a Vulnerability

Please do not report security issues in public GitHub issues or pull requests.

Report them to the TYPO3 Security Team via security@typo3.org. The team
coordinates the fix and the publication of a security advisory with the
maintainers.
